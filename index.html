05 EXPORT

How it is computed
  • Pose: MediaPipe Pose Landmarker (33 keypoints) run frame by frame; short gaps are interpolated and signals Gaussian-smoothed
  • Camera: background texture is tracked between frames (person masked out), so paths and holds are measured in wall coordinates even when the camera pans
  • CoM: centre of mass from segment mass fractions (Dempster / de Leva) — trunk 49.7%, thigh 10%, etc.
  • Metric scale: trunk length (shoulders → hips) ≈ 0.29 × stature
  • Fluency: log dimensionless jerk (LDLJ) of the CoM during each move; closer to 0 = smoother
  • Path entropy (GIE): log₂(2L/c) of the CoM path (Cordier / Seifert); lower = more direct, less hesitation
  • Straight-arm rest: share of resting time with an elbow >150° — hanging on the skeleton instead of the muscles
  • Foot:Hand: foot placements per hand grab, from detecting hands/feet held still for ≥0.4 s

All values are estimates from single-camera 2D video. They work best for comparing the same climber on the same problem over time. The Flow score is this app's own formula and has not been validated against research data.
